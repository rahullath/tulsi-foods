# Tulsi orders on WhatsApp: what you'll see, what to do

*One page for the kitchen. Print it and keep it near the POS.*

Messages come to the **shop WhatsApp (99400 62840)** from **Tulsi Foods
(+1 555-397-2507)**. Save that number as "Tulsi Orders Bot".

## The one trick: swipe right to reply

To answer any message from the bot, **swipe it to the right** (or press and
hold → Reply), type, and send. The bot knows which order or customer it was
about. No order numbers needed.

## Every order

1. **The POS rings.** Check the items and the note. Tap **Accept**.
   The customer is told automatically.
2. **Delivery order? A "Book a Porter" message arrives.** It has the
   address, the map pin, the phone number and the cash to collect.
3. **Book the Porter 2-wheeler**, then **swipe right on that message** and
   send the Porter link and the fare, e.g. `https://porter.in/… ₹86`.
   The customer gets the rider's live link. (The customer already paid
   ₹49–₹89 delivery; the fare is only for our records.)
4. **Food ready → Food Ready on the POS. Rider left → Delivered.**
   The customer gets a message each time, and a "Rate your food" button.

## When the bot sends you these

| You see | What to do |
| --- | --- |
| 💬 *"Asha asks: …"* | Swipe right and type your answer. It goes to Asha. |
| 📎 *"Asha sent a photo"* (UPI screenshot) | Check your UPI app. If the money came, send **paid 42** (the order number). Asha is told. |
| 🔔 *"Book a Porter now"* | Book, then swipe right and send the link and fare. |

## Things you can type to the bot

| Type | It does |
| --- | --- |
| **orders** | Today's website / WhatsApp orders and their status |
| **paid 42** | Marks order 42's UPI payment received and tells the customer |
| **dal tadka sold out** | Hides a dish for today |
| **dal tadka back** | Shows it again |
| **special mango lassi 89** | Sets today's special |
| anything else | Shows this list |

## If something goes wrong

| Problem | Do this |
| --- | --- |
| Bot says the customer's chat is quiet for 24 hours | WhatsApp won't let us message them. Call the customer. |
| No Porter message after accepting | Book anyway from the POS details, then send the link and fare to the bot with the order number: `#42 https://porter.in/… ₹86`. |
| Customer wants to cancel | Cancel on the POS. They are told automatically. Refund UPI orders. |
| Anything else | Tell Rahul. |
